# Моделирование и расчет полосковой линии (Microstrip Line)

Репозиторий содержит результаты проектирования, аналитического расчета и трехмерного электромагнитного моделирования полосковой линии передачи, оптимизированной для работы на частоте **1.015 ГГц**.

Проект включает в себя математический синтез геометрии линии под стандартный 50-омный тракт, создание CAD-моделей и полноволновой анализ характеристик согласования в среде численного моделирования.

---

## Структура проекта

* `/cad` — трехмерная геометрия конструкции в форматах SolidWorks (`.sldprt`) и нейтральном (`.step`).
* `/calculations` — аналитические расчеты параметров линии в Mathcad (`.xmcd`).
* `/simulation` — проект численного электромагнитного анализа в CST Studio Suite (`.cst`).
* `/docs/images` — графические результаты расчетов и графики частотных характеристик.

---

## Аналитический расчет параметров

Математический расчет геометрических параметров выполнен в среде Mathcad. В качестве подложки выбран диэлектрик толщиной 1 мм с относительной диэлектрической проницаемостью $\varepsilon = 3.38$.

![Аналитический расчет](docs/images/calc_microstrip_analytical.png)

### Исходные и расчетные параметры:
* **Целевое волновое сопротивление ($Z_B$):** 50 Ом
* **Ширина полоска ($b$):** 4.098 мм
* **Предельная частота моды высшего порядка ($F_{crit}$):** 82.15 ГГц
* **Коэффициент затухания ($\alpha$):** 0.345 дБ/м

---

## 3D-модель и геометрия

На основе рассчитанных размеров построена связанная полосковая структура на диэлектрической подложке с заземляющим экраном. Возбуждение ВЧ-сигнала осуществляется с помощью дискретных портов (Discrete Ports).

![3D-модель в CST](docs/images/simulation_3d_model.png)

---

## Результаты электромагнитного моделирования

Анализ частотных характеристик проводился в диапазоне 0.8–1.2 ГГц. Точка оптимального согласования структуры зафиксирована на частоте $f_0 = 1.015$ ГГц.

### Ключевые параметры на частоте 1.015 ГГц:

| Параметр | Обозначение | Значение | Описание |
| :--- | :---: | :---: | :--- |
| Коэффициент отражения | S11 | -28.86 дБ | Низкий уровень отражения, подтверждающий согласование тракта. |
| КСВН | VSWR1 | 1.086 | Значение близко к единице во всей рабочей полосе частот. |
| Входной импеданс | Z11 | 50.49 Ом | Соответствует стандартному тракту 50 Ом. |
